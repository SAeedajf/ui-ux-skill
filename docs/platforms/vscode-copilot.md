# VS Code and GitHub Copilot

Current VS Code documentation lists `.github/skills/`, `.agents/skills/`, and `.claude/skills/` as project skill locations. Install to `.github/skills/` when targeting Copilot conventions, or use the repo's `.agents/skills/` directly when supported by the selected agent host. Discovery does not guarantee invocation.

Current reference: [Use Agent Skills in VS Code](https://code.visualstudio.com/docs/agent-customization/agent-skills).
