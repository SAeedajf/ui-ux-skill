# Claude Code

Install project-level copies into `.claude/skills/` with the installer. Keep the directory name equal to the frontmatter `name`. Start a new session or refresh skills, then use `/skills` to inspect availability. Claude Code may invoke a Skill when relevant; you can also call it directly as a slash command, for example `/ui-ux-review`. Direct invocation is not an automatic-activation evaluation. See the [AI agent usage guide](../agent-usage-guide.md) for task scoping and evidence labels.

Current reference: [Claude Code Skills](https://code.claude.com/docs/en/skills).
