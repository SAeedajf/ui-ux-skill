# Codex

Use `.agents/skills/` as the canonical project-level location. Open the repository as a project and check that the intended Skills appear in the active host. The `SKILL.md` files use the common `name` and `description` frontmatter fields. For API/sandbox use, the parent skill directory must be made available to the execution environment according to that API's current configuration.

Current reference: [OpenAI Skills guide](https://developers.openai.com/api/docs/guides/tools-skills).
