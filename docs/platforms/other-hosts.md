# Other compatible hosts

The skills use the common Agent Skills folder format: one directory per Skill, a `SKILL.md` manifest, and optional supporting references. A compatible host may still require a different parent path or additional metadata. Consult current host documentation, copy the skill folder to its discovery path, and verify it appears before relying on automatic invocation. See the [AI agent usage guide](../agent-usage-guide.md) for a host-neutral selection and evidence workflow.
