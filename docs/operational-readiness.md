The activation validator now also binds an activation PASS to a non-empty JSONL trace, a SHA-256 of the trace reviewed, review scope, reviewer/time, and referenced event lines. This guards against a PASS row pointing to an arbitrary file, but it still relies on a human reviewer to decide whether a cited host event actually proves automatic Skill invocation. No current activation result has that review attestation; quality results use a separate criterion-level review and do not substitute for activation evidence.
