# Example: web landing-page review

**Request:** Review a product landing page for clarity and mobile usability. No user research or analytics were supplied.

**Scope:** Inspect the page's rendered wide and narrow states, title/CTA hierarchy, semantic headings, and actual focus order. Record viewport sizes and whether keyboard checks were run.

**Example finding:** The primary action appears after two visually stronger secondary links on the narrow layout. This is an observed hierarchy issue, not evidence of conversion loss. Recommend moving the main action adjacent to the value statement and reducing competing emphasis. Verify with a task-focused review and, if conversion impact matters, a measured experiment.

**Evidence:** Use registry IDs 3 or 7 for relevant visual guidance, 65/67 for responsive behavior, and 81 for the applicable WCAG criteria. Confirm the exact claim against the linked page; a homepage alone is not claim-level evidence.

**Verification boundary:** This example illustrates reporting format. It is not a report on a real page and no checks are claimed as performed.
