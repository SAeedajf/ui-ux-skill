# Example: web landing-page review

**Request:** Review a product landing page for clarity and mobile usability. No user research or analytics were supplied.

**Scope:** In a real review, inspect the page's rendered wide and narrow states, title/CTA hierarchy, semantic headings, and actual focus order. Record viewport sizes and whether keyboard checks were run.

**Hypothetical finding only:** If inspection showed the primary action after two visually stronger secondary links on the narrow layout, record that as an observed hierarchy issue for that inspected state—not as evidence of conversion loss. A possible proposal would move the main action adjacent to the value statement and reduce competing emphasis. Verify the actual page before making a finding; measure user outcomes separately if conversion impact matters.

**Evidence:** Use registry IDs 3 or 7 for relevant visual guidance, 65/67 for responsive behavior, and 81 for the applicable WCAG criteria. Confirm the exact claim against the linked page; a homepage alone is not claim-level evidence.

**Verification boundary:** This example illustrates reporting format. It is not a report on a real page; the finding is conditional and no checks are claimed as performed.
