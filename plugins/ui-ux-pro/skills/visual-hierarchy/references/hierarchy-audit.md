# Visual hierarchy audit

## Audit sequence

- Name the primary user task and the most consequential choice or information.
- List visible content and annotate each item as primary, secondary, or supporting, with a short task-based reason.
- Describe the intended scan path. Check whether position, size, grouping, whitespace, type weight, and contrast support it without making multiple items compete as primary.
- Verify actual labels, content density, state, and viewport; a hierarchy recommendation from a text inventory alone is provisional.
- Compare visual sequence with semantic, reading, and keyboard order. Confirm controls remain discoverable at zoom and when localized text expands.
- Pair color with text, shape, or position where meaning matters. Contrast measurement belongs to `color-systems` and broader conformance to `accessibility-inclusive-design`.
- State the smallest task-based validation that could disconfirm the proposed order.
