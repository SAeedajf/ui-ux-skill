# Skill index

The canonical Skills live in `.agents/skills/`. Each can be installed separately.

| Skill | Use it for |
|---|---|
| `ux-discovery` | User goals, research evidence, and unresolved product questions |
| `journey-mapping` | End-to-end journeys, service experience, and evidence-labeled maps |
| `information-architecture` | Content grouping, taxonomy, labels, and findability validation |
| `interface-layout` | Page composition, spacing, cards, and layout |
| `visual-hierarchy` | Content priority, emphasis, and intended scan order |
| `color-systems` | Semantic color roles, palettes, themes, and contrast checks |
| `ethical-persuasion` | Transparent influence, conversion, engagement, and habit-forming UX |
| `interaction-patterns` | General control behavior, states, feedback, and recovery |
| `forms-input` | Form fields, input constraints, validation, and error recovery |
| `navigation-controls` | Wayfinding, route menus, action buttons, and current-location cues |
| `design-systems` | Tokens, reusable components, consistency, and system governance |
| `responsive-design` | Responsive web and adaptive Android behavior across windows and devices |
| `accessibility-inclusive-design` | Accessibility requirements, inclusive interaction, and verification |
| `persian-rtl-localization` | Persian/RTL localization while preserving mixed-direction content |
| `ui-ux-review` | Evidence-based UI/UX inspection and actionable review reports |

Use `ui-ux-review` for a broad audit. For a focused change, invoke the task Skill directly; combine Skills only when the task crosses their boundaries. See [domain coverage](../docs/domain-coverage.csv).
