# Ui Ux Review

## Workflow
1. Establish scope, user tasks, audience, platforms, locales, target states, constraints, and available evidence.
2. Inspect the actual interface or code at representative sizes and states; distinguish code inspection, rendered inspection, automated checks, and user testing.
3. Prioritize findings by user impact and confidence. Each finding includes location, evidence, consequence, recommended change, and verification step.
4. Map findings to applicable standards, research, platform guidance, or clearly labeled design judgment using source IDs. Do not claim conversion impact without relevant measurement.
5. Provide a concise summary, ordered findings, verified aspects, and explicit unknown/unverified areas.

Use `references/review-template.md`; invoke focused Skills for deeper follow-up.
