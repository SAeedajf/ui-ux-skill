# Review report template

## Scope and evidence
- Interface/revision, platform, locale, task, audience, states, viewport/device:
- Inspected evidence: code / rendered UI / automated tools / manual assistive technology / user research:
- Not inspected:
- Baseline and comparison: initial behavior, established root cause (if any), before/after evidence, and regression checks:

## Findings
For each finding: **priority and rationale**, **location/state**, **evidence class and source IDs**, **user impact**, **confidence with rationale**, **recommended change**, **verification**. Label each finding as a normative requirement, platform guidance, research finding, user-reported issue, inference, or design judgment as applicable.

## Strengths and constraints
List what supports the task and which existing patterns should be preserved.

## Verification status
List checks completed and their exact boundaries. Mark unknowns explicitly; do not claim an overall accessibility or usability pass based on partial inspection.
