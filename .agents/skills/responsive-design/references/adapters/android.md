# Android adapter

Use Android platform guidance when the target is a native Android app. Inspect the actual UI toolkit and app structure before proposing APIs. Review touch and keyboard input, TalkBack semantics, text scaling, window resizing, orientation, multi-window/foldable behavior, adaptive navigation, and state restoration where relevant.

Starting source IDs include 11, 42, 66, 72, 82, 89, and 97. APIs and design guidance can change; verify current Android documentation for implementation details.
